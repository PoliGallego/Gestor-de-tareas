# Gestor de tareas

## Pasos para la ejecución de los backends:
1. mvn clean install a la altura de la carpeta "shared"
2. Ejecutar el backend del login
3. Ejecutar el backend de paneles
4. Ejecutar el backend del dashboard

## Pasos para la ejecución de los frontends:
1. Ejecutar el frontend de login
2. Ejecutar el frontend de sign up
3. Ejecutar el frontend principal
4. Ejecutar el frontend de dahsboard
